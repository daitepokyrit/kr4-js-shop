# PACE — KR4: JavaScript-магазин

Учебный многостраничный проект к практическим занятиям №14–15. Это статический frontend на HTML, CSS и vanilla JavaScript: без backend, React, npm и сборщика. Сохраняется запуск открытием `index.html`; каталогу, локальной корзине и профилю интернет не требуется. Внешняя карта в футере загружается при наличии сети.

## Страницы

- `index.html` — главная и витрина.
- `catalog.html` — карточки моделей, поиск, фильтр по назначению и размеру, сортировка.
- `product.html` — подробная страница товара по `?id=`.
- `cart.html` — корзина с изменением количества, удалением и итогом.
- `order.html` — форма заявки с валидацией и сообщениями об ошибках.
- `about.html`, `contacts.html`, `account.html` — информация, контакты и демонстрационный профиль.

## Как устроен JavaScript

`js/data.js` объявляет единый массив `window.PACE_PRODUCTS` с шестью моделями. На страницах он подключён перед `js/main.js`, оба скрипта используют `defer`. `main.js` строит карточки каталога и список моделей в форме заказа из одного массива, форматирует цены, фильтрует и сортирует товары, открывает модальное окно, управляет корзиной и формой.

Корзина и учебный профиль хранятся в `localStorage` текущего браузера. Заказ никуда не отправляется: страница показывает демонстрационное подтверждение. Данные карты, контактные реквизиты и цены — учебные.

## Функции JavaScript из задания

- Объект товара и массив данных в `js/data.js`.
- `formatPrice`, фильтрация, поиск и сортировка товаров.
- Расчёт суммы корзины при изменении состава.
- `calculateDiscount`, `calculateFinalPrice`, `getProductStatus` и `createProductSummary` вынесены в начало `js/main.js`; карточки и корзина используют финальную цену и статус наличия.
- Динамическая отрисовка через `innerHTML` для статических учебных данных; пользовательский текст формы выводится через `textContent`.
- Ошибки формы, состояние корзины, количество товара и сумма доступны в DevTools Console для отладки.

## Запуск и структура

Откройте `index.html` в браузере. Все фотографии находятся локально в `images/real/`.

```text
kr4-js-shop/
├── index.html, catalog.html, product.html, cart.html, order.html
├── about.html, contacts.html, account.html
├── js/data.js
├── js/main.js
├── css/style.css
├── css/responsive.css
└── images/
```
